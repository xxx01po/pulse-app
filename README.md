# PULSE — Life OS

PULSE is a mobile-first personal operating system for goals, daily planning, quests, and progress.

## Stack
- React + TypeScript + Vite
- Framer Motion
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Current scope
The first frontend prototype includes Home, Quests, AI Companion, Progress, and Profile. Demo tasks and XP are stored locally in the browser. Authentication, secure server-side XP validation, AI provider integration, database persistence, and payments are not yet connected.
